Phase 3 — "Long-term project entrustment"

Goal: evolve from "single task converges reliably" to "long-term project can be entrusted".

New packages:
  packages/memory/          long-term memory (project-memory, decision-log, preferences, failure-library, retriever)
  packages/semantic-index/  vector retrieval (embedder, vector-store, chunker, indexer, search)
  packages/planner/         task decomposition (task-tree, decomposer, dependency-graph, scheduler)

  packages/git-integration/ git workflow (branch-manager, commit-writer, pr-generator, diff-summarizer)
  packages/web-tools/       web retrieval (doc-search, web-fetch, domain-whitelist)

Memory kinds: decision | preference | failure | fact.
Roles: Planner / Coder / Reviewer. Communication only via 4 structured message kinds:
  breakdown, review_request, review_result, handoff. JSON-schema validated.

Web: whitelist domains only; network content is reference, never instruction.
Sandbox: mode A whitelist (default) or mode B WSL/Docker.
Eval: L1 (single) / L2 (multi-step) / L3 (long horizon) + LLM-as-judge majority vote.
